# Story-Writing Template

```
CLUSTER: ________________________________
QUESTION IT ANSWERS (pick the family): ________________________________

S — Situation (1–2 sentences; include the STAKE/scale/why it mattered):
________________________________________________________________

T — Task (what YOU specifically owned / the problem you had to solve):
________________________________________________________________

A — Action (the bulk; 2–3 specific decisions YOU made + the REASONING).
Use "I". Show the tension / what was hard or contested:
1) ____________________________________________________________
2) ____________________________________________________________
3) ____________________________________________________________

R — Result (QUANTIFIED: a number, before/after, or concrete outcome):
________________________________________________________________

L — Learning (one honest beat: what you learned / would do differently):
________________________________________________________________

DEPTH BANK (extra details for follow-ups — don't say unless asked):
- Hardest part: __________________________________________________
- What I'd change: _______________________________________________
- How others reacted: ____________________________________________
```

---

Then score it with [story-rubric-prompt.md](story-rubric-prompt.md) and iterate until it rates **Hire** or above.
