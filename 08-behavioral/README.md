# 08 — Behavioural

| File | What it's for |
|---|---|
| [frameworks.md](frameworks.md) | **Start here.** STAR / SPSIL / SAIL, what's actually graded, why stories fail, hypotheticals, ready-made answers to "how do you decide / define scope", outage storytelling, red flags. |
| [question-bank.md](question-bank.md) | Questions grouped into ~10 competency clusters, with the follow-ups to expect, plus company-style question lists. |
| [story-template.md](story-template.md) | Fill-in template, one per cluster. |
| [story-rubric-prompt.md](story-rubric-prompt.md) | A paste-into-any-LLM rubric that scores a written story harshly on the Google hiring scale. |
| [questions-to-ask.md](questions-to-ask.md) | Questions for interviewers, recruiters, and team-matching calls. |

**Process:** pick one real experience per cluster → write it in the template → score it with the rubric → fix the top issue → repeat until it's rated Hire → rehearse a 90-second version out loud.
